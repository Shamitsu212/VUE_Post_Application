# 📄 Приложения для просмотра постов

Это базовый проект на Vue 3, созданный для демонстрации знаний работы с Vue и Vue Router.
Приложение позволяет:
Просматривать посты, полученные с API JSONPlaceholder
Добавлять и удалять посты локально
Понимать базовую структуру SPA на Vue
